# Avorium API

Yerel kurulum, örnek ortam değişkenleri ve demo verileri için [ana README](../README.md) dosyasına bakın. API Express, Prisma ve MySQL kullanır.

Komutlar: `npm run dev`, `npm run typecheck`, `npm run build`, `npm run db:push`, `npm run seed` ve `npm run seed:demo`. Kategori seed'i mevcut kategorileri silmez; demo seed'i yalnızca yerel veritabanında çalışır.
